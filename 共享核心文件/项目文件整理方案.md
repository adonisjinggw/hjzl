# 📁 项目文件夹整理方案

## 🎯 整理目标
将本地开发和网络部署相关文件分别组织到对应文件夹中，提升项目可维护性。

## 📂 建议的文件夹结构

```
📁 项目根目录/
├── 📁 deployment/                    # 部署相关文件
│   ├── 📁 local/                     # 本地部署
│   │   ├── *.bat                     # 本地启动脚本
│   │   ├── test-*.html               # 本地测试文件
│   │   └── vite.config.local.ts      # 本地配置
│   ├── 📁 cloudflare/                # Cloudflare部署
│   │   ├── wrangler.toml             # Cloudflare配置
│   │   ├── vite.config.cloudflare.ts
│   │   ├── deploy-to-cloudflare.bat
│   │   └── Cloudflare部署指南.md
│   ├── 📁 github/                    # GitHub部署
│   │   ├── .github/workflows/
│   │   ├── GitHub相关文档.md
│   │   └── GitHub配置脚本.bat
│   └── 📁 simple/                    # 简化部署版本
│       ├── simple-deploy/
│       ├── enhanced-deploy/
│       └── index-simple.html
├── 📁 src/                           # 核心源码（不变）
├── 📁 docs/                          # 项目文档（不变）
├── 📁 scripts/                       # 构建脚本（不变）
├── 📁 backups/                       # 备份文件（不变）
├── 📁 tools/                         # 开发工具
│   ├── 📁 mcp/                       # MCP相关
│   │   ├── interactive-feedback-mcp/
│   │   ├── .taskmaster/
│   │   └── mcp_*.json
│   ├── 📁 diagnostic/                # 诊断工具
│   │   ├── 原始诊断测试.bat
│   │   ├── 检查应用状态.bat
│   │   └── 清理项目文件.bat
│   └── 📁 api-config/                # API配置
│       ├── 配置谷歌API.bat
│       ├── 配置免费API.bat
│       └── 相关配置文档.md
└── 📁 temp/                          # 临时文件
    ├── *.zip                         # 临时压缩包
    ├── working-*.html               # 工作副本
    └── test-*.html                  # 测试文件
```
